# analysis/ — 硬证据层

`journal/` 记录"我们做了什么"，`docs/` 记录"我们知道了什么"，
而 **`analysis/` 存放的是"结论是怎么被推出来的"** —— 带地址、带偏移、带命令，
任何人都能照着复现一遍。

## 内容原则

1. **可复现**：每条结论都必须写出"从哪个文件、用什么工具、看哪个地址"得出。
2. **区分事实与推测**：事实用陈述句，推测一律标注 `[推测]` 并写清理由与反例风险。
3. **带原始证据**：保留关键反汇编片段、字符串偏移、文件哈希。
4. **可被推翻**：如果后续实验推翻了某条结论，**不删旧文**，在文件头加 `[已推翻]` 并链接新结论。

## 命名规则

```
NN-主题.md
```

`NN` 两位序号，只增不改号。文件内首行用 `# 标题`，第二段列出
**证据文件 / 工具 / 关键地址** 三要素。

## 与其它目录的关系

```
/analysis  →  一手证据与推理链（本目录）
/docs      →  面向人的整合叙述
/journal   →  按时间线的事件日志
/hashes.md →  文件身份台账
```
